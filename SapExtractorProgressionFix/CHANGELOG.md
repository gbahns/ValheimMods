# Changelog

## 0.1.0 — 2026-11-23

First release.

- Sap extractors credit the whole time you were away instead of discarding it on return.
- The ancient root refills before its extractors collect from it.
- An extractor drains the root only by what it actually collected.
- Log Catch Up (on by default) writes one line per extractor on return, saying what the unmodified game would have done.
